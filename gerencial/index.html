Como criar o token (uma vez só)
  1. Abra github.com → Settings → Fine-grained tokens
  2. Dê um nome (ex.: gerencial-bg) e uma validade
  3. Repository access: Only select repositories → bg-login
  4. Permissions → Repository → Contents: Read and write
  5. Generate token → copie e cole aqui
